# Диалектика

Браузерная философская RPG по мотивам диалогов Платона.

Играй в три главы: «Евтифрон», «Лахет», «Критон». Спорь с Сократом, набирай опыт, улучшай отношения с персонажем и получай предметы. На устройстве сохраняется игровой прогресс.

## Как запустить

- [Открыть игру](https://psycho-53.github.io/dialektika-game/) — после включения GitHub Pages.
- Локально: открой `index.html` в браузере.

## Как включить GitHub Pages

1. Открой **Settings → Pages** в этом репозитории.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку **main**, папку **/(root)** и нажми **Save**.

После публикации игра будет доступна по адресу: https://psycho-53.github.io/dialektika-game/

Проект независим от `dnevnik`.
