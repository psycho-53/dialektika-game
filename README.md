# Диалектика 2.0 — философская игра по Платону

«Диалектика» — бесплатная русскоязычная браузерная игра с 75 эпизодами по мотивам «Евтифрона», «Лахета» и «Критона». Есть карта, философские испытания, система навыков, суд над Сократом, библиотека и личный дневник.

Открыть: https://psycho-53.github.io/dialektika-game/

## Основные свойства
- Не использует платные модели ИИ, серверную базу или аналитику.
- Прогресс хранится **только на устройстве** в localStorage. Экспорт / импорт JSON доступны в меню ⋯.
- После первого посещения под HTTPS основные экраны и фреска доступны без сети благодаря service worker. На iPhone можно добавить сайт на домашний экран через меню «Поделиться» → «На экран Домой».
- Установка на главный экран не переносит сохранение автоматически между браузерами: для этого предназначен экспорт/импорт.
- Игровые реплики — художественная адаптация платоновских диалогов, не дословные исторические цитаты Сократа.

## Исходный код
- `index.html`, `styles.css`, `game.js` — приложение.
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-оболочка.
- `assets/school-of-athens.jpg` — репродукция подлинной «Афинской школы» Рафаэля. Произведение в общественном достоянии. Репродукция: Wikimedia Commons, https://commons.wikimedia.org/wiki/File:The_School_of_Athens_by_Raffaello_Sanzio_da_Urbino,_Vatican.jpg .
