# Диалектика 1.3

Игра по мотивам диалогов Платона. 75 эпизодов в трёх главах, мини-игры, философский дневник, карта Афин и прогресс.

- Откройте `index.html` через веб-сервер или GitHub Pages.
- Стили: `styles.css`; игра и диалоги: `game.js`.
- Прогресс остаётся в `localStorage` под старым ключом; поддерживаются экспорт и импорт JSON.

Литературные игровые реплики по мотивам диалогов, не дословные цитаты исторического Сократа.
